# DoctorBot

Telegram bot for paid online consultations with doctors and other experts.

The project retains the original payment gateways, referrals, user search, broadcasts,
plans, admin flows, and layered architecture. Its consultation domain supports expert
profiles, multiple experts per client, multiple clients per expert, payment idempotency,
and one-to-one relay through paired topics in the client's and expert's private chats
with the bot. No Telegram groups are required.

See [README.ru_RU.md](README.ru_RU.md) for setup and operating instructions.
