# DoctorBot

Telegram-сервис платных онлайн-консультаций с врачами и другими экспертами.

Проект сохраняет исходную архитектуру бота, платежные шлюзы, реферальную систему,
поиск пользователей, рассылки, тарифы и административные сценарии. Новая бизнес-логика
добавляет роли клиента и эксперта, каталог анкет, подписки на нескольких экспертов и
изолированные консультации.

> Сервис не предназначен для экстренной медицинской помощи и не выполняет
> автоматическую диагностику.

## Как устроены консультации

1. Клиент выбирает активную анкету эксперта и тариф.
2. Платежная транзакция сохраняет выбранного эксперта.
3. После подтверждения платежа создаётся или продлевается консультация.
4. Бот создаёт связанную тему в личном чате клиента с ботом и отдельную связанную
   тему в личном чате эксперта с ботом.
5. Сообщения из темы клиента копируются только в тему назначенного эксперта.
6. Ответы из темы эксперта копируются только в тему соответствующего клиента.

Группы и supergroup не используются. Одна консультация всегда связывает ровно одного
клиента и одного эксперта. Клиент не видит других клиентов эксперта, а эксперт не может
открыть консультации другого эксперта.

## Настройка

Скопируйте `.env.example` в `.env` и заполните обычные настройки приложения, базы,
Redis, Telegram-бота и платежных шлюзов. Дополнительно откройте Mini App `@BotFather`,
выберите бота и включите `Topics` / `Threaded Mode` в его настройках. При запуске
приложение проверяет поле
`has_topics_enabled` и останавливается с понятной ошибкой, если режим не включён.

VPN-режим необходимо отключить:

```env
APP_LEGACY_VPN_ENABLED=false
```

Старые Remnawave-поля и таблицы оставлены для безопасной миграции существующей базы,
но при `APP_LEGACY_VPN_ENABLED=false` Remnawave webhook, HAPP endpoint и проверка панели
при запуске отключены.

### Локальный запуск на macOS через Docker

Для Telegram webhook нужен публичный HTTPS-адрес. Для разработки можно использовать
временный Cloudflare Quick Tunnel.

```bash
cp .env.example .env
make setup-env
brew install cloudflared
cloudflared tunnel --url http://localhost:5000
```

Из адреса вида `https://example.trycloudflare.com` запишите в `.env` только домен:

```env
APP_DOMAIN=example.trycloudflare.com
BOT_TOKEN=токен_из_BotFather
BOT_OWNER_ID=ваш_числовой_Telegram_ID
BOT_SUPPORT_USERNAME=username_без_символа_собака
APP_LEGACY_VPN_ENABLED=false
```

`make setup-env` автоматически создаёт `APP_CRYPT_KEY`, `BOT_SECRET_TOKEN`,
`DATABASE_PASSWORD` и `REDIS_PASSWORD`. Остальные параметры PostgreSQL и Redis для
Docker можно оставить со значениями по умолчанию. Затем во втором терминале запустите:

```bash
docker compose -f docker-compose.local.yml up --build
```

Контейнер приложения сам выполняет `alembic upgrade head`. Для повторного запуска
используйте ту же команду без очистки volume. Команда `make run-local reset` удаляет
локальные данные PostgreSQL и Redis, поэтому используйте её только когда действительно
нужна чистая база.

До первой покупки и клиент, и эксперт должны хотя бы один раз открыть бота и нажать
`Start`: Telegram не позволяет боту первым начинать личный диалог с пользователем.

## Миграции и запуск

```bash
alembic -c src/infrastructure/database/alembic.ini upgrade head
python -m src
```

Миграция `0023` создаёт `expert_profiles`, `expert_plans`, `consultations` и
`expert_subscriptions`, добавляет роль `EXPERT` и связывает платежи с анкетами.

## Администрирование

- назначение пользователю роли `EXPERT` автоматически создаёт черновик анкеты;
- активировать или отключить анкету можно в карточке пользователя;
- отключённая анкета исчезает из каталога, существующие консультации не удаляются;
- повторить создание темы после ошибки можно командой `/retry_consultation ID`;
- изменить поле анкеты можно командой
  `/expert_edit ID name|specialization|short|description|experience|photo ЗНАЧЕНИЕ`;
- вручную завершить консультацию можно командой `/consultation_close ID`;
- восстановить ошибочно завершённую консультацию с ещё действующим оплаченным
  сроком можно командой `/consultation_restore ID`;
- истёкшие консультации каждые пять минут становятся неактивными; темы и история
  остаются на месте, но бот прекращает передачу новых сообщений.

Команды изменения анкет и консультаций проверяют право `EXPERT_EDITOR`; обычный
пользователь и эксперт выполнить их не могут. В карточке пользователя администратор
видит выбранных экспертов, число активных консультаций, а для эксперта — количество
клиентов, завершённых консультаций и связанных платежей.
